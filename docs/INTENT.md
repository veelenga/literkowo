# Intent

Literkowo is a typing game for children.
This page explains the idea behind it. [SPEC.md](SPEC.md) describes how the game works today.

## The idea

1. **Type quickly and correctly with all ten fingers.**
   Children learn real touch typing, not hunting for keys with two fingers.
2. **Stay fun for a long time.**
   The game keeps children entertained, so they come back to it on their own.
3. **Easy to start, easy to keep going.**
   It opens in a browser on any device with nothing to install, and every session moves the child forward.
4. **Explain things correctly.**
   Finger placement, hand position and which finger presses which key are taught properly.
   The right technique is there from the first level.
5. **Progress at the right pace.**
   New keys come only when the earlier ones are solid.
   Difficulty follows the child.
   Accuracy comes before speed. The game rewards careful typing, and a mistake costs the combo.
   A new mechanic must keep careful typing as the best way to win.
   An idea that rewards speed over accuracy does not fit.

## Who it is for

Children from about 9 years old who are learning to type.
Several children can share one device, each with their own profile.

## For now

- There are no accounts and no server today. Nothing leaves the browser.
- More interface and typing languages may be added later.
- Literkowo may one day be released as a product. Decisions today should not block that.

When a change does not fit this page, talk about it before building it.
